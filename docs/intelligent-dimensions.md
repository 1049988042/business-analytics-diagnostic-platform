# 第二阶段：智能维度定位

系统在叶子指标页面自动请求 `/api/analysis`。Metric Tree 和分层 Shapley 保持第一阶段口径。

```json
{
  "metric": "visitors",
  "operation": "dimension_analysis",
  "recommendation": "auto",
  "filters": {"months": ["2017-03"], "channel": "", "device": ""},
  "scope": []
}
```

`recommendation:auto` 由服务端将当前可用维度填入原有 dimensions 查询计划。明确传 dimensions 仍支持渠道、设备独立请求和并列基础结果；不能同时要求 auto 和指定非空 dimensions。没有新增专用查询接口。

点击分组把 `{dimension,value}` 加入 scope。全局 filters 始终保持原始值；服务端校验冲突后合并查询范围，不覆盖全局限制。scope 固定的维度、全局固定的维度均从扫描范围删除。重复维度、空 scope 值和冲突条件被拒绝。

## 确定性评分

位置：`lib/discovery/recommendation.ts`。版本 `dimension-signal-v2`，不是 AI、统计显著性或因果模型。

每个候选维度分别计算，所有中间值保留精度。先删除无法计算变化、未知维度值和样本不足的组，仅从推荐中排除，完整分组表保留。

- 访客等数量指标：两期至少一期分组访客达到 50；购买访客需至少一期购买访客 20。
- 购买转化率：两期分母访客都至少 100。
- 客单价与购买频次：两期交易数/购买访客分母都至少 20。
- 非比率指标组强度 = abs(分组变化)；比率指标组强度 = abs(分组变化) × 该组两期平均分母 / 全部分组平均分母合计，仅作探索评分权重，不称数学贡献。
- G = 有效组强度之和，P/N = 增加/减少组强度；正负分别保留。
- 规模 S = G / (G + 0.05 × 两期父指标绝对值均值 + floor)。floor：收入 100 USD、交易数 5、客单价 1 USD、转化率 0.0001、购买频次 0.01、人数 20。
- 集中程度 C = (最大组强度/G − 1/n) / (1 − 1/n)，截取到 [0,1]，用均匀分组基准减少分组数差异影响。
- 抵消程度 O = 2 × min(P,N) / G，不除以整体净变化。
- 样本质量 Q = 有效组分母规模占比 × min(1,两期父范围最小访客/200) × 有效变化强度占全部变化强度比例。
- 有效组数因子 F = 1 − 1/(n+1)；少于两个有效组时 F=0。
- score = 100 × Q × F × (0.5S + 0.3C + 0.2O)。至少 15 分且有非零变化才可推荐。

前两名分差 ≤ max(5 分,第一名的 10%) 时返回 ambiguous，dimension=null，choices 列出接近的方向。没有足够信号返回 insufficient，不制造唯一赢家。没有剩余维度返回 exhausted。排序相同结果采用维度名稳定排序，仅用于展示，平局不指定唯一赢家。

reason 为结构化 code/text/values 数组，包含规模、集中、正负抵消和样本依据；总体 reason 提供状态、分差、接近阈值。highlights 在服务端选取每个方向最多三个有效分组，excluded 标明不参与推荐的理由。

## 交互

`app/dimension-analysis.tsx` 自动扫描、显示推荐或平局选择、分组变化和“继续分析”。当前指标路径与维度范围分别标记，返回上一级移除最后一个 scope 条件。完整分组和评分依据默认折叠。没有拖拽、并列维度 UI 或交叉矩阵。

访客/购买访客一律显示去重人数的分组变化，保留 exactContribution=false 和重叠说明；不展示分组占整体净变化贡献率。加总型指标仍由第一阶段底座校验分组合计。

## 性能与测试

数学指标页面仍 3 次 SQL；首次无固定维度的叶子定位为 5 次 SQL（核心周期聚合1、渠道1、设备1、版本前后检查2）；固定一个维度后为4次。每个请求核心聚合只执行一次。原有浏览器缓存和 sourceVersions 验证继续使用，返回上级可命中原缓存。不解析 GA JSON/hits，不预计算组合。

`tests/recommendation.test.ts` 验证渠道/设备互换优先、平局、正负抵消、零变化、单分组、未知维度、低样本、过滤冲突、自动维度、scope 双向查询与防循环。`tests/dimension-render.test.tsx` 验证推荐内容、平局按钮、面包屑、返回和末端提示。第一阶段测试继续运行。

本地 196,817 条模拟会话、7 次新连接、无应用缓存对照：原单维度叶子约431ms，新双维度叶子约677ms；父 GMV 页面约199ms，限定 Organic Search 范围后的剩余维度约183ms。这是 SQLite 模拟测试，OS 页缓存没有清空，不能称作生产 D1 冷查询实测。
