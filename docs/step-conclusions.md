## 维度层
访客数入口不显示维度结论。选择渠道/设备后展示对应结论。结论开头使用 API 已合并的范围：无筛选为“在全局筛选范围内（全部渠道、全部设备）”；渠道下设备为“在 [真实渠道] 渠道范围内”；设备下渠道为“在 [真实设备] 设备范围内”。

Distinct 使用满足既有样本条件分组的增加/减少，不宣称精确贡献率；ratio 同时列出比例、分子和分母前后值；additive 使用既有正负分组金额/数量。所有数字最后格式化，不重算归因或推荐。
