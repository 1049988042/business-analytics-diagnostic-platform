# 公开演示版

在原站点提供公开只读体验，保留所有者后台能力。默认选择 2017-03，展示与 2017-02 的比较。

访客允许：GET meta/dashboard/analysis/discover；POST analysis/query（查询由既有白名单 SQL 生成器构建）。禁止访客访问其他 API，包括 ask、model-test、saved、admin、settings、sample、import/*、semantic/*。访问限制在 payload 解析、数据库及模型调用之前执行；不依赖前端隐藏按钮或 visitor_enabled 设置。

前端隐藏访客 AI、数据管理及已保存分析入口，保留经营看板、指标树、维度推荐、下钻和本步结论。展示个人项目和 GA 公开样例数据说明。没有公开原始数据下载、个人保存内容或管理信息。

验证：42 组匿名受限路由测试返回 403，测试 runtime 在任何数据库或密钥访问时抛错，以确保未触达后台；仅匹配邮箱但无认证用户 ID 也被拒绝。访客主界面测试验证默认月份、隐藏受限入口、KPI 进入及延迟加载。指标分析交互回归与类型检查通过。

上线顺序：先部署包含服务端访问控制的新版本，再将站点访问范围改为 public，避免旧版在权限收紧前公开。

## 独立演示站 v2
数据已导入 2017-01、2017-02、2017-03。所有账号统一只读，包括所有者；后台、导入、模型和个人保存 API 均关闭，/admin 返回首页。仅独立演示站应用这些限制，私有工作站不受影响。匿名及认证所有者的 84 次受限接口请求均返回 403，界面测试以 owner=true 验证仍无管理和 AI 入口。
