# 2027 届数据分析求职素材

项目：经营数据智能诊断平台（Business Analytics Diagnostic Platform）

## 一句话

基于 GA 电商会话数据，将指标变化发现、数学拆解、维度定位和行为诊断整合为可交互、可追溯的分析流程。

## 3 条简历版

- 基于 2017 年 1—3 月 19.68 万条电商会话，建立 GMV、交易数、访客、购买转化率和购买频次指标体系，明确周期去重、金额单位及分母口径。
- 运用分层 Shapley 拆解 GMV 和交易数变化，通过贡献守恒校验识别推动与抵消；复核 3 月 GMV 环比增长 20.42%，交易数推动约 3.64 万美元、客单价抵消约 1.42 万美元。
- 实现渠道/设备双向下钻和范围继承，区分可加、去重及比例指标，将每步结果转为确定性结论，避免虚假贡献率和无依据因果解释。

## 4 条简历版

- 梳理 GA 会话及商品行为口径，规范化处理 19.68 万条会话、87.13 万条 hits，建立经营 KPI 与固定指标树。
- 使用分层 Shapley 分配多因素交互项，验证 GMV 和交易分支守恒，定位历史案例的交易数推动与客单价抵消。
- 设计统一维度分析请求，支持渠道→设备、设备→渠道，结合变化规模、集中程度及样本质量提供确定性推荐。
- 通过去重重叠、零分母、scope 冲突、反向变化及接口权限测试验证边界，形成可追溯的本步结论和行为诊断线索。

按本人实际参与程度调整措辞；不要把每次代码改进写成成果，也不要无依据使用“独立从零完成”。

## 技术关键词

SQL 聚合、指标体系、Metric Tree、分层 Shapley、环比分析、distinct、scope、渠道/设备分析、行为诊断、数据质量、参数化查询、SQLite/D1、TypeScript、确定性规则、缓存失效。

|---|---|

| 7 个指标节点、3 个公式节点 | Metric Tree，不等于首页卡片数 |
| 2 个可靠维度 | 渠道、设备 |
| GMV +20.42%、净增 $22,207.75 | 线上报告汇总经当前代码复算 |
